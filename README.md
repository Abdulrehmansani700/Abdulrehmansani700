### 🏗️ Featured Projects

**🔹 IoT Cloud Migration Pipeline**
On-premise IoT sensor data migrated to a full AWS + Snowflake cloud pipeline — IoT Core → MSK → Kafka Connect → PostgreSQL, then Debezium CDC → Kafka → Snowflake → dbt, visualized in a live Streamlit dashboard.

**🔹 TrendPulse — YouTube Trending Data Pipeline**
Event-driven, fully serverless AWS pipeline ingesting YouTube trending data via the YouTube Data API, processed through S3 → Lambda → DynamoDB, and visualized in Power BI.

**🔹 CloudRide — NYC Taxi Data Pipeline**
Batch pipeline processing 2.9M+ rows of NYC taxi trip data using Python, boto3, S3, AWS Glue Crawler, Glue ETL, and Athena for querying.

**🔹 Real-Time Weather Alert Pipeline**
Live weather data pipeline pulling from the OpenWeatherMap API through Python and boto3, storing to S3 with automated SNS alerts.
